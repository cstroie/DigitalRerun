ZORK I: The Great Underground Empire
====================================

Play it:      D:
              VEZZA ZORK1.Z3

Save and restore inside the game with SAVE and RESTORE (give a file
name such as ZORK1.SAV). QUIT leaves the game.

ZORK1.Z3   the game (Infocom, release 119 / serial 880429), from
           github.com/historicalsource/zork1 (COMPILED/zork1.z3).
           Microsoft released Zork I under the MIT licence in 2025:
           see ZORK1.LIC. ZORK is a trademark; the licence does
           not cover trademarks.
VEZZA.COM  Vezza, a Z-machine interpreter for CP/M by Shawn Sijnstra,
           the vezza-C2 build (80x24, VT100), from
           gitlab.com/sijnstra1/vezza (commit 8bb76168, 2026-04-19).
           GPL-2.0-or-later: see VEZZA.LIC. Its author publishes
           the builds there and plans to publish the source.
