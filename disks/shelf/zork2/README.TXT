ZORK II: The Wizard of Frobozz
=====================================

Play it:      PLAY      (types VEZZA ZORK2.Z3 for you)
              or VEZZA ZORK2.Z3

Save and restore inside the game with SAVE and RESTORE (give a file
name such as ZORK2.SAV). QUIT leaves the game.

ZORK2.Z3   the game (Infocom), from github.com/historicalsource/zork2
           (COMPILED/zork2.z3). Microsoft released it under the MIT
           licence in 2025: see ZORK2.LIC. ZORK is a trademark; the
           licence does not cover trademarks.
VEZZA.COM  Vezza, a Z-machine interpreter for CP/M by Shawn Sijnstra,
           the vezza-C2 build (80x24, VT100), from
           gitlab.com/sijnstra1/vezza. GPL-2.0-or-later: see VEZZA.LIC.
PLAY.COM   types the line above at the CP/M prompt, so you need not.
