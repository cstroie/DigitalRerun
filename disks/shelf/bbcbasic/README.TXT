BBC BASIC (Z80)
===============

Start it:     BBCBASIC
Then:         LOAD "MANDEL"      load an example (MANDEL, PRIMES, GUESS, BANNER)
              LIST               see it
              RUN                run it
              SAVE "MINE"        keep your own program (as MINE.BBC)
              *BYE               back to CP/M

The examples are here twice: NAME.BBC for LOAD, NAME.BAS to read with
TYPE. BANNER prints a large heading on the printer (see PAPER).
