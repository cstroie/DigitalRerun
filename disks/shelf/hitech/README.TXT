HI-TECH C 3.09 for Z80 CP/M
===========================

Compile and run:   C -V HELLO.C      compile and link HELLO.COM (-V shows each pass)
                   HELLO             run it
                   C -H              the options
                   C -O -V PROG.C    optimised

The manual is HTCZ80.TXT. The library sources (and much more) are at
github.com/agn453/HI-TECH-Z80-C.

The HI-TECH Z80 CP/M C compiler V3.09 is provided free of charge for any
use, private or commercial, strictly as-is, and its copyright remains
with HI-TECH Software (see HITECH.LIC). This disk holds release
V3.09-21, with the updates collected by Tony Nicholson (C.COM is
C309-21.COM; LINQ.COM is its linker, renamed to avoid the CP/M name).
HELLO.C was written for DigitalRerun.
