BDS C 1.60
==========

Compile and run:   CC HELLO          compile HELLO.C to HELLO.CRL
                   CLINK HELLO       link it to HELLO.COM
                   HELLO             run it

More examples are in EXAMPLES.LBR:  LBREXT EXAMPLES  takes them out,
LDIR EXAMPLES  lists them. READ.ME and FILES.DOC are the release notes.
The full User's Guide (PDF) is at www.bdsoft.com/resources/bdsc.html.

BDS C was written by Leor Zolman (BD Software) and released into the
public domain on 20 September 2002: compiler, linker, libraries,
utilities and documentation. This disk holds the CP/M-80 v1.60 files
from that release (bdsc-all.zip); HELLO.C was written for DigitalRerun.
