SUBMARINE SABOTAGE
==================

Play it:      PLAY      (types VEZZA SUBSAB.Z3 for you)
Save and restore inside the game with SAVE and RESTORE (give a file
name). QUIT leaves the game.

SUBSAB.Z3  the game, by Garry Francis.
           Listed as freeware in the Interactive Fiction Database and
           kept, unchanged, in the IF Archive
           (ifarchive.org/if-archive/games/zcode/). Its author keeps the
           rights: it may be shared, not sold.
PLAY.COM   types the line above at the CP/M prompt, so you need not.
VEZZA.COM  Vezza, a Z-machine interpreter for CP/M by Shawn Sijnstra,
           the vezza-C2 build (80x24, VT100), from
           gitlab.com/sijnstra1/vezza. GPL-2.0-or-later: see VEZZA.LIC.
