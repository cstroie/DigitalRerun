ZORK III: The Dungeon Master
=====================================

Play it:      VEZZA ZORK3.Z3

Save and restore inside the game with SAVE and RESTORE (give a file
name such as ZORK3.SAV). QUIT leaves the game.

ZORK3.Z3   the game (Infocom), from github.com/historicalsource/zork3
           (COMPILED/zork3.z3). Microsoft released it under the MIT
           licence in 2025: see ZORK3.LIC. ZORK is a trademark; the
           licence does not cover trademarks.
VEZZA.COM  Vezza, a Z-machine interpreter for CP/M by Shawn Sijnstra,
           the vezza-C2 build (80x24, VT100), from
           gitlab.com/sijnstra1/vezza. GPL-2.0-or-later: see VEZZA.LIC.
