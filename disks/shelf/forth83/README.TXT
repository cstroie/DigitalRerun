FORTH-83 (F83) for CP/M
=====================================

Run it:       F83
Try:          2 3 + .      : SQ DUP * ;   7 SQ .
Leave:        BYE

F83.COM       the Forth system, by Henry Laxen and Michael Perry
              (version 2.0, 1983-84). Public domain: the authors ask only
              that they are credited and no copyright notice is put on it.
              See README.80 (their instructions) and F83FIXS.TXT.
KERNEL80.BLK  source of the kernel     EXTEND80.BLK  of the extensions
UTILITY.BLK   source of the utilities
F83.LIC       the public domain dedication of the copy this was taken from
              (github.com/janaite/forth83-80, the unchanged contents of
              F83V2-80.ARK from the Forth Interest Group's archive).

The metacompiler (META80.BLK), the 8080 code (CPU8080.BLK) and the
examples (CLOCK.BLK, BASIC.BLK, HUFFMAN.BLK) did not fit; they are in
that repository.
